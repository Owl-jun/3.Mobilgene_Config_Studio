■ 제품 개요
--------------------------------------------------------------------------------
Mobilgene Config Studio는 AUTOSAR / Mobilgene(Odin) 워크스페이스의 ARXML 설정을
읽기 전용으로 탐색·분석하는 도구입니다.

  · ECU 설정 파일(Ecud_*.arxml) 트리 탐색
  · Gateway I-PDU 매핑 표 보기
  · BSW 모듈 구조 맵
  · 컨테이너 간 REF(참조) 연결 추적
  · 워크스페이스 기호 검색 (SID, 컨테이너 이름 등)

※ 본 버전은 설정 파일을 조회·분석하는 뷰어입니다. ARXML 저장·편집 기능은
  포함되어 있지 않습니다.


■ 시스템 요구 사항
--------------------------------------------------------------------------------
  · 운영체제 : Windows 10 / 11 (64비트)
  · 웹 브라우저 : Microsoft Edge 또는 Google Chrome
                (앱 창 표시용 — 일반적으로 Windows에 기본 설치됨)
  · 디스크   : 약 150MB 이상 여유 공간
  · 기타     : Python, Node.js 등 별도 설치 불필요


■ 폴더 구성
--------------------------------------------------------------------------------
  Start.bat                  ← 실행 권장 (더블클릭)
  MobilgeneConfigStudio.exe  ← 메인 실행 파일
  README.txt                 ← 본 매뉴얼
  _internal\                 ← 프로그램 내부 파일 (삭제·이동 금지)
  ui\                        ← 화면 리소스


■ 실행 방법
--------------------------------------------------------------------------------
  [방법 1] Start.bat 더블클릭 (권장)
    1. 검은색 콘솔 창이 열리며 서버가 시작됩니다.
    2. 잠시 후 Edge/Chrome 앱 창에 Mobilgene Config Studio가 표시됩니다.

  [방법 2] MobilgeneConfigStudio.exe 직접 실행
    · Start.bat과 동일하게 동작합니다.

  ※ 앱 창이 뜨지 않으면
    · Edge 또는 Chrome이 설치되어 있는지 확인하세요.
    · 콘솔 창에 표시된 주소(예: http://127.0.0.1:8765)를 브라우저에 직접
      입력해 보세요.


■ 종료 방법
--------------------------------------------------------------------------------
  1. 앱 창(브라우저)을 닫습니다.
  2. 콘솔 창에서 Ctrl+C 를 누르거나, 콘솔 창을 닫습니다.

  ※ 콘솔 창을 닫으면 프로그램이 완전히 종료됩니다.


■ 화면 구성
--------------------------------------------------------------------------------
  ┌─────────────┬──────────────────────────┬─────────────────┐
  │  파일 트리   │   설정 뷰 / 구조 맵        │   속성 패널      │
  │ (ARXML 목록) │   (트리·매핑표·그래프)     │   (상세 정보)    │
  └─────────────┴──────────────────────────┴─────────────────┘

  [상단]
    · 워크스페이스 경로 입력란 — Mobilgene 프로젝트 루트 폴더 지정
    · [찾아보기] — 폴더 선택
    · [열기] — 워크스페이스 분석 시작

  [중앙 상단 탭]
    · 구조 맵 — BSW 모듈 간 연결 관계 다이어그램
    · 파일 상세 — 선택한 ARXML 파일 내용

  [파일 상세 — Gateway.arxml]
    · 매핑 테이블 — I-PDU Source → Target 한눈에 보기 (권장)
    · 원본 XML — ARXML 트리 구조 (고급 사용자용)


■ 기본 사용 절차
--------------------------------------------------------------------------------
  1단계. 워크스페이스 열기
    · 상단에 Mobilgene 프로젝트 루트 경로를 입력합니다.
      예) D:\Project\my_ecu_working
    · [열기]를 클릭합니다.
    · 왼쪽 파일 트리에 Configuration/Ecu/Ecud_*.arxml 등이 표시됩니다.

  2단계. 파일 선택
    · 파일 트리에서 분석할 ARXML을 클릭합니다.
    · 중앙에 해당 파일의 설정 뷰가 표시됩니다.

  3단계. 항목 탐색
    · XML 트리에서 컨테이너(예: DcmConfigSet, SID10_...)를 펼칩니다.
    · 항목을 클릭하면 오른쪽 속성 패널에 파라미터·REF 연결 정보가 표시됩니다.

  4단계. REF 따라가기
    · 속성 또는 테이블의 파란색 REF 링크를 클릭하면
      참조 대상 파일·항목으로 이동합니다.


■ 주요 기능 안내
--------------------------------------------------------------------------------
  [워크스페이스 검색]
    · 중앙 패널 상단 검색창에 2글자 이상 입력 (예: SID10, PduR)
    · 결과 클릭 시 해당 파일·위치로 이동

  [Gateway I-PDU 매핑]
    · Gateway.arxml 선택 → [매핑 테이블] 탭
    · Source 버스 / PDU → Target 버스 / PDU 표 형식
    · 상단 필터로 버스·PDU 이름 검색 가능

  [컨테이너 연결 분석]
    · Ecud_*.arxml 트리에서 ECUC 컨테이너 선택
    · 속성 패널에서
        - 「이 컨테이너 → 연결」 : 이 항목이 가리키는 REF
        - 「← 이 컨테이너를 참조」 : 다른 곳에서 이 항목을 가리키는 REF

  [구조 맵]
    · [구조 맵] 탭에서 BSW 모듈 결합 관계 확인
    · 모듈 클릭 시 해당 Ecud_*.arxml로 이동


■ 워크스페이스 폴더 기준
--------------------------------------------------------------------------------
  일반적인 Mobilgene 워크스페이스 루트에는 다음이 포함됩니다.

    Configuration/Ecu/Ecud_*.arxml     ECU BSW 설정
    Configuration/System/DBImport/     Gateway, DBC 등
    Generated/                           생성물 (읽기 참고용)

  ※ Generated 폴더는 빌드 산출물이므로, 분석 시 참고만 하시기 바랍니다.


■ 자주 묻는 문제 (FAQ)
--------------------------------------------------------------------------------
  Q. 앱 창이 안 열려요.
  A. Edge/Chrome 설치 여부를 확인하고, 콘솔에 표시된 URL을 브라우저에
     직접 입력해 보세요. Windows 방화벽에서 로컬(127.0.0.1) 접속을
     허용해야 할 수 있습니다.

  Q. 「서버 구버전」 또는 기능이 동작하지 않아요.
  A. 이전에 실행한 MobilgeneConfigStudio가 남아 있을 수 있습니다.
     작업 관리자에서 종료 후 Start.bat을 다시 실행하세요.

  Q. 트리 아래 항목이 안 보여요.
  A. ▶ 버튼을 눌러 펼치거나, [펼치기] 버튼으로 상위 계층을 확장하세요.
     로딩에 수 초 걸릴 수 있습니다.

  Q. 포트 충돌이 나요.
  A. 기본 포트 8765가 사용 중이면 프로그램이 자동으로 다른 포트를
     사용합니다. 콘솔 창의 URL을 확인하세요.

  Q. 다른 PC로 옮기려면?
  A. MobilgeneConfigStudio 폴더 전체를 복사합니다.
     _internal 폴더를 반드시 함께 복사해야 합니다.


■ 배포·복사 시 주의
--------------------------------------------------------------------------------
  · 폴더 이름을 바꿔도 되지만, 내부 파일·하위 폴더 구조는 유지하세요.
  · _internal, ui 폴더를 삭제하거나 분리하면 실행되지 않습니다.
  · 네트워크 드라이브에서 실행 시 속도가 느릴 수 있습니다.
    가능하면 로컬 디스크에 복사 후 실행하세요.
